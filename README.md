# Surf Maroc · Quel spot

Web app installable (PWA) : quel spot cibler à Dar Bouazza et sur la côte atlantique marocaine, maintenant et sur 3 jours.

- Prévisions en direct depuis Open-Meteo (houle GFS-Wave, vent GFS + ICON, marée), aucun serveur à faire tourner.
- Fonctionne hors-ligne avec les dernières prévisions chargées.
- Site statique : `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`.

## Mise en ligne sur Render
Le fichier `render.yaml` décrit un site statique. Pousse ce dossier sur GitHub, puis ouvre
`https://dashboard.render.com/blueprint/new?repo=<URL du dépôt>` et clique sur Apply.

## Installer sur iPhone
Ouvre l'adresse du site dans Safari, touche Partager, puis « Sur l'écran d'accueil ».

Données : Open-Meteo, gratuit pour un usage personnel non commercial.
